This folder contains the code for the Advent of Code 2025.

## Code structure
The code is structured in the following way:

- `advent_of_code_2025`: The main package containing the code for the Advent of Code 2025.
- `advent_of_code_2025/utils`: Utility functions for the Advent of Code 2025.
- `advent_of_code_2025/examples`: Example applications for the Advent of Code 2025.
- `advent_of_code_2025/tests`: Tests for the Advent of Code 2025.
- `advent_of_code_2025/data`: Data files for the Advent of Code 2025.

## Usage
To run the code, you need to have Python 3.8 or later installed.
To run the tests, you need to have pytest installed.
