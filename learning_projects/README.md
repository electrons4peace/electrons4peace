# This folder contains the code for the HMM learning project.

## Objective of the project

The objective of this project is to learn and implement a Hidden Markov Model (HMM) and the algorithms Baum-Welch and Viterbi algorithms on a theoretical dataset.

## Dataset
An artificial dataset was generated to be used for the project. The dataset contains specified number of states, observations.

## Code structure
The artificial dataset is generated in the `generate_dataset.py` file.
